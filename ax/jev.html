Jev: 언어 이해를 소프트웨어의 판단 함수로 연결하기

Jev는 글을 쓰는 생성형 AI가 아니라, 텍스트 상태를 읽고 미리 정한 답 안에서 확률·선택·점수를 반환하는 판단 모델이다. AX 관점에서는 생성 모델을 대체하기보다 빠른 분류와 라우팅을 맡는 부품으로 보는 편이 정확하다.

한 문장 정리

Jev가 정하고, 생성형 AI가 쓴다.
Jev는 의미 판단을 제한된 값으로 돌려주고, OpenClaw·Claude·ChatGPT 같은 생성형 시스템은 그 판단을 바탕으로 설명·문서 작성·도구 실행을 이어간다.

판단의 세 가지 원형

Noul · 참일 확률

“이 메시지가 환불을 요구하는가?”처럼 예·아니오로 정의된 명제의 확률을 0~1로 반환한다.

Choice · 보기 중 선택

미리 정한 후보 중 하나와 후보별 확률을 반환한다. 기타·정보 부족 후보를 함께 설계해야 강제 오분류를 줄일 수 있다.

Score · 단계 점수

2~10개 서술형 등급을 기준으로 분포와 가중 점수를 반환한다. 평균만 보지 말고 등급별 분포도 함께 봐야 한다.

장점과 단점

장점
  • 자유문장이 아닌 제한된 타입으로 받아 코드 연결이 쉽다.
  • 짧고 반복적인 의미 판단에서 속도와 비용 이점이 크다.
  • 한 상태에 여러 질문을 묶어 중복 입력과 네트워크 왕복을 줄일 수 있다.
  • 후보별 확률을 보존해 사람 검토·자동 처리 기준을 설계할 수 있다.
  • 업무별 재학습 없이 질문과 기준을 요청마다 바꿀 수 있다.
단점·주의
  • 글쓰기, 요약, 자유로운 설명, 긴 추론을 하지 못한다.
  • 형식이 맞는 것과 의미가 정확한 것은 별개다.
  • 높은 확신도가 실제 정답률을 뜻하지 않으므로 자체 평가가 필요하다.
  • 이미지·음성·영상은 직접 입력할 수 없다.
  • 중요한 실행은 사실 조회·규칙·권한 검사를 별도로 통과해야 한다.
  • 가격·한도·모델 버전은 바뀔 수 있어 운영 모니터링이 필요하다.

실행OpenClaw 도구
설명생성형 AI 작성

1. 블로그 발행 전 품질 게이트

  • 중복 문단, 개인정보, 위험 표현 포함 가능성을 Noul로 검사한다.
  • 글 유형과 카테고리를 Choice로 고르고, 완성도를 Score로 평가한다.
  • Jev는 통과·보류 판단만 하고 실제 문장 수정과 발행은 OpenClaw와 사람이 맡는다.

2. 맛집·장소 링크 자동 분류

  • OpenClaw가 링크에서 장소·상호·지역 텍스트를 추출한다.
  • Jev가 맛집·카페·여행지·숲·보류 중 하나를 고른다.
  • 검증된 임계값 이상만 자동 저장하고 나머지는 사람에게 확인한다.

3. 작업·문의 라우팅

  • 블로그, 숲해설, 개인 프로젝트, 회사업무 등 처리 영역을 Choice로 분류한다.
  • 긴급도와 중요도를 별도 Score로 평가해 우선순위를 만든다.
  • 회사업무는 보안등급을 먼저 확인하고 민감 원문은 외부 API에 보내지 않는다.

안전한 도입 원칙

작게 검증
  1. 비민감 샘플 30건으로 한국어 정확도 측정
  2. 실제 정답과 확률·확신도 비교
  3. 오분류 비용에 따라 자동화 임계값 설정
  4. 모델 버전이 바뀔 때 회귀 테스트
권장 책임 경계
  • Jev: 의미 분류와 점수화
  • 코드: 사실 조회, 계산, 권한, 중복 실행 방지
  • 생성형 AI: 설명과 초안 작성
  • 사람: 낮은 신뢰도와 되돌리기 어려운 결정 승인
회사 자료 주의
외부 API에는 회사업무 LV3·LV4 원문, 개인정보, 내부 설정값, 쿼리, 대외비 문서를 전송하지 않는다. 필요하면 비식별화한 LV1 수준 예시만 사용한다.

도입 로드맵

  1. 키 준비: TypeSafe 콘솔에서 시험용 API 키를 별도로 발급하고 공유 파일·저장소에 기록하지 않는다.
  2. 전용 도구: OpenClaw에서 Jev를 일반 채팅 모델이 아닌 `jev_decide` 판단 도구로 연결한다.
  3. 평가셋: 블로그 품질 점검과 장소 분류 각각 최소 30건을 수작업 정답과 비교한다.
  4. 임계값: 자동 처리, 사용자 확인, 기존 모델 재검토의 세 구간을 정한다.
  5. 운영: 모델 버전·응답시간·비용·오분류를 기록하고 정기적으로 기준을 보정한다.
