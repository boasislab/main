핵심 내용

핵심 관점

Skill은 업무를 일회성 채팅에서 반복 가능한 작업 시스템으로 끌어올린다.

업무 적용

instruction layer는 작업 규칙, 예시, 평가 기준, 기억을 문서화하는 제어 표면이다.

운영 포인트

강력한 Skill은 문서화된 규칙이 도구, 파일, 코드, 외부 시스템과 연결될 때 나온다.

세부 포인트

  • Skill은 업무를 일회성 채팅에서 반복 가능한 작업 시스템으로 끌어올린다.
  • instruction layer는 작업 규칙, 예시, 평가 기준, 기억을 문서화하는 제어 표면이다.
  • 강력한 Skill은 문서화된 규칙이 도구, 파일, 코드, 외부 시스템과 연결될 때 나온다.

원문 수준 상세 정리

원문을 그대로 복제하지 않고, 원문 목차와 논리 흐름을 따라 세부 주장·판단 기준·실행 단계를 촘촘하게 재구성했습니다.

Skill은 반복 업무 시스템이다

  • AI를 잘 쓰는 차이는 긴 프롬프트가 아니라 반복 작업을 안정적인 구조로 재사용하는 데서 난다.
  • AI Skill은 프롬프트 파일 하나가 아니라 반복 업무의 실행 단위다.

md 파일은 제어 표면이다

  • md 파일 구조는 Skill의 전체 실행 환경이 아니라 control surface다.
  • 실제 Skill이 강력해지는 지점은 문서화된 규칙이 도구, 파일, 코드, 외부 시스템과 연결될 때다.

파일별 역할

  • description은 라우터다.
  • SKILL.md는 실행 명세다.
  • examples는 참조 데이터다.
  • evals.md는 테스트다.
  • memory.md는 상태 저장소다.

Editor와 Grader 분리

  • AI가 직접 만든 결과물을 같은 맥락에서 바로 평가하면 자기합리화가 생길 수 있다.
  • 초안을 개선하는 Editor Agent와 기준에 따라 검수하는 Grader Agent를 분리하면 품질 편차를 줄일 수 있다.

좋은 Skill 후보

  • 지난 일주일 동안 자주 반복했고 매번 비슷한 기준으로 판단했던 일이 후보가 된다.
  • 강의안 편집, 뉴스레터 작성, 제안서 검토, 코드 리뷰, 법령 요약, 고객 문의 답변, 회의록 정리 등이 적합하다.

실행 계층으로 확장

  • 도구, 스크립트, API, MCP, 파일 입출력은 실제 작업을 수행하는 실행 계층이다.
  • Skill이 외부 데이터와 도구에 연결되면 업무 파이프라인이 된다.

여준님 업무에 적용할 때

  • 반복 업무마다 실행 규칙, 예시, 금지어, 평가 기준을 파일로 분리한다.
  • 좋은 결과물 샘플과 실패 기준을 함께 둔다.
  • 작업 후 개선점을 기억 구조에 반영한다.
