FOREIGN BOND MBS · FIVE-YEAR REVIEW

해외채권 MBS를 이해하고
새로운 상품구조에 대비하기

구축 당시의 합리적인 설계가 시간이 흐르며 왜 예외처리 중심 구조로 변했는지, 현업의 눈높이에서 함께 이해하기 위한 브리핑입니다.

핵심 메시지: 과거 설계가 잘못됐다기보다, 당시 알려진 유형을 중심으로 최적화한 구조가 새로운 혼합형 상품의 변화를 충분히 흡수하지 못하는 시점에 도달했습니다.
MBS 정의구현배경설계배경현행구조새 상품 문제고도화 방향보강정보

1. MBS란 무엇인가

일반 개념 MBS는 주택담보대출에서 발생하는 원금과 이자 현금흐름을 기초로 발행되는 채권형 증권입니다.

일반 채권과 다른 점

예정된 만기상환 외에 기초 대출의 조기상환이 현금흐름과 듀레이션을 바꿀 수 있습니다.

시스템이 알아야 할 것

발행·보증주체, 지급규칙, 원리금 배분, 조기상환, 통화·결제 및 평가 속성입니다.

에이전시 유형의 의미

발행·보증 구조와 지급특성이 일정한 대표 유형을 분류해 처리규칙을 선택하는 기준이 됩니다.

2. 왜 시스템으로 구현했는가

현업 확인 필요 아래 내용은 현재까지의 운영 맥락을 바탕으로 한 구현배경 설명모델입니다.

상품정보 수신
유형 판정
현금흐름 관리
평가·손익
회계·결제
대사·마감

수작업의 한계

  • 상품별 원리금과 조기상환 처리 반복
  • 평가·회계·결제 간 동일한 분류 필요
  • 해외 데이터와 내부 원장 대사 부담

구축 당시의 목표

  • 대표 에이전시 유형을 표준 처리
  • 상품정보에서 후속 업무까지 연결
  • 일관된 현금흐름·회계·결제 결과 제공

3. 당시 설계가 합리적이었던 이유

구축 시점에 관찰된 대표 유형의 특성이 충분히 안정적이라면, 에이전시 유형을 중심으로 공통규칙을 묶는 것은 빠르고 안정적인 방법입니다.

당시 조건설계 선택얻은 효과
대표 유형이 비교적 명확유형코드 중심 분류판정과 후속처리 단순화
유형별 지급특성이 반복정해진 규칙 재사용개발·검증 범위 축소
업무 안정화가 우선지원 범위를 명확히 제한회계·결제 정합성 확보
중요: 5년간 안정적으로 운영됐다면 초기 설계는 당시 요구에 효과적으로 대응한 것입니다. 현재의 문제는 시간이 흐르며 상품 다양성이 초기 분류 경계를 넘어선 데 있습니다.

4. 현행 시스템 구조가 만들어진 과정

1차 진단 가설 에이전시 유형이 여러 후속 업무의 처리전략을 동시에 선택하는 중심키 역할을 하는 구조로 추정합니다.

5. 새로운 상품에서 왜 문제가 생기는가

새 상품이 기존 유형 하나와 정확히 일치하지 않고 여러 유형의 속성을 섞거나 새로운 지급규칙을 가지면 유형코드 하나로 전체 처리를 결정하기 어렵습니다.

기존 분류 방식

  • 유형 A이면 규칙 A 전체 적용
  • 유형 B이면 규칙 B 전체 적용
  • 유형별 필수 입력항목이 고정

새 상품의 가능성

  • 발행·보증 특성은 A와 유사
  • 현금흐름은 B와 유사
  • 새로운 조기상환·결제 특성 보유
현재 확인할 핵심: 새 상품이 기존 유형과 다른 지점이 발행주체인지, 원금·이자 배분인지, 조기상환인지, 데이터 제공형식인지에 따라 실제 개선대상이 달라집니다.

6. 고도화 방향: 유형명이 아니라 속성과 규칙으로

에이전시 유형은 참고 분류로 유지하되, 실제 처리는 상품의 구조적 속성과 독립된 규칙 조합으로 결정합니다.

STEP 1

상품 차이 정의

기존 유형과 새 상품의 구조적 차이를 속성 단위로 분해합니다.
STEP 2

규칙 위치 추적

분산된 조건문과 수작업을 영향영역별로 모읍니다.
STEP 3

속성·규칙 외부화

공통 규칙은 데이터로, 복잡 계산은 전략모듈로 분리합니다.
STEP 4

회귀테스트 자산화

기존·신규 유형의 대표 결과를 자동 비교합니다.

7. 현업 사실로 보강할 정보

자료 요청 아래 내용이 채워지면 가설을 실제 시스템 진단으로 바꿀 수 있습니다.

① 최초 지원유형초기에 구분한 에이전시 유형과 각 유형의 핵심 차이
② 새 상품상품명 또는 내부 구분, 기존 유형과 달라진 구조적 특성
③ 문제 발생지점등록·현금흐름·평가·회계·결제·대사 중 막히는 단계
④ 현재 예외처리어떤 값을 바꾸거나 수작업·프로그램 분기를 추가하는지
⑤ 결과 위험오류·지연·재처리·검증 부담과 발생 빈도
⑥ 기대 처리새 상품을 정상 처리했을 때 단계별 예상 결과
우선 새 상품 1건을 기준으로 “기존 유형과 같은 점 / 다른 점 / 현재 우회처리 / 원하는 정상처리” 네 가지만 알려주시면 다음 버전에서 실제 사례 중심으로 보강할 수 있습니다.
